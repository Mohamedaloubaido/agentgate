# Contributing

Thanks for contributing to AgentGate.

## Development expectations

- Keep changes small and testable.
- Add or update tests for evaluator behavior.
- Do not commit secrets or API keys.
- Keep provider-specific logic behind interfaces.
- Prefer deterministic tests over live model calls in CI.

## Commit style

Use concise conventional-style commits when practical, for example:

- `feat: add baseline run comparison`
- `fix: handle empty required terms`
- `docs: document trace span model`
